# Hollow Reach: Game Foundation

Hollow Reach is a single-player tactical extraction and survival-strategy game
set in an isolated mining settlement built around damaged geothermal works.

The player fantasy is to become a resourceful expedition lead who turns limited
information into safe routes, useful salvage, and hard choices for the settlement.

## Core loop

Survey a sector, choose a route and loadout, extract salvage, then invest the
return in settlement readiness before conditions shift.

## Design pillars

- **Information creates advantage.** Observation and preparation should matter
  more than reflex speed alone.
- **Every haul carries a tradeoff.** Valuable salvage consumes time, capacity,
  and attention.
- **The settlement remembers.** Reviewed choices should shape later pressures
  without removing uncertainty.
