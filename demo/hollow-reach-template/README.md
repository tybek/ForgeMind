# Hollow Reach Demo Template

This directory is the pristine, public-safe ForgeMind DEMO-0 workspace template.
Do not record against or edit this copy. Duplicate the entire directory to a new
recording workspace, then open that duplicate through **Open Existing Project**.

The initial project state is intentionally sparse so Knowledge Import can add
reviewed material during the demo. Use `docs/combat-direction.md` for the import
path. See [`docs/DEMO_RUNBOOK.md`](../../docs/DEMO_RUNBOOK.md) for the complete
operator procedure and fallback plan.
