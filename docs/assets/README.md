# Public submission assets

This directory is reserved for current, public-safe ForgeMind screenshots and other submission media. Do not commit fabricated UI, private dogfood content, credentials, raw provider output, absolute machine paths, or screenshots from an outdated build.

Use the synthetic **Hollow Reach** demo workspace from the [DEMO-0 Runbook](../DEMO_RUNBOOK.md). Capture only after the applicable manual workflow is in a known, truthful state.

Suggested filenames:

- `overview-control-room.png` - Project Overview with the clean Hollow Reach baseline;
- `game-wiki.png` - Game Wiki showing source/authority labels;
- `knowledge-import-review.png` - Candidate Review Queue after a real, reviewed extraction;
- `writers-room-source-trace.png` - Writers' Room with Project Brain sources and, if useful, selected Tavily research;
- `tavily-external-research.png` - bounded external-research drawer with public-safe results; and
- `ai-models.png` - Token Factory catalog versus enabled registry, verified capability, and observed local metrics.

The root README currently reserves four locations: Overview, Knowledge Import, Writers' Room/source trace, and AI Models. Three or four strong images are preferable to a feature gallery. Replace each matching `SCREENSHOT TODO` comment with a normal Markdown image only after the image exists and has passed public-safety review.

Before committing an image:

- verify that no notification, terminal, key, user profile, private path, or unrelated window is visible;
- verify that the UI matches the submitted build;
- keep model metrics labeled as local observations rather than benchmarks;
- keep external sources labeled `EXTERNAL_RESEARCH`; and
- confirm the image is intentional and licensed for public use.
