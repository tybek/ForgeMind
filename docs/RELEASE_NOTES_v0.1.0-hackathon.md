# ForgeMind v0.1.0 — Hackathon Demo Build

**Tag:** `v0.1.0-hackathon`

Windows test build prepared for the Nebius x NVIDIA Global AI Hackathon. This is a feature-frozen evaluator build, not a production-readiness claim.

## Highlights

- Review-first Markdown Knowledge Import with explicit human Apply.
- Project Brain and Game Wiki with source and provenance visibility.
- Source-aware Writers' Room with reviewed proposal application.
- Explicit Tavily external research kept separate from project truth.
- Structured AI workflows using Nebius Token Factory and NVIDIA Nemotron.
- Read-only Git and Unity evidence with human-reviewed Alignment.

## Evaluator notes

- API credentials are not bundled in this release.
- Live Nebius Token Factory / NVIDIA Nemotron and Tavily functionality requires evaluator-provided credentials.
- Local and read-only product areas can be inspected without developer credentials.
- The public demo video and README provide the primary walkthrough of the complete reviewed AI workflow.

See the repository README for setup, security, scope, and current limitations.
